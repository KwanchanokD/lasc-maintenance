ระบบดูแลครุภัณฑ์และเครื่องมือวิทยาศาสตร์

ศูนย์บริการสัตว์ทดลอง มหาวิทยาลัยสงขลานครินทร์ · สำหรับเจ้าหน้าที่เท่านั้น

🔐 เข้าสู่ระบบเจ้าหน้าที่

เปิดไฟล์จากเครื่องโดยตรง (file://) จะเข้าสู่ระบบไม่ได้
กรุณาเปิดจากเว็บที่ตั้งค่า HTTPS ไว้ (ดู README.md)
หรือเข้าสู่ระบบด้วยอีเมลและรหัสผ่าน

ระบบนี้เปิดให้เฉพาะเจ้าหน้าที่ที่ได้รับสิทธิ์จากผู้ดูแลระบบเท่านั้น — ไม่มีการสมัครสมาชิกเอง

⏳ กำลังเชื่อมต่อระบบ…

⛔ บัญชีนี้ยังไม่มีสิทธิ์เจ้าหน้าที่

เข้าสู่ระบบด้วย สำเร็จแล้ว แต่บัญชีนี้ยังไม่อยู่ในรายชื่อเจ้าหน้าที่

รหัสผู้ใช้ (UID) ของบัญชีนี้:

วิธีเพิ่มสิทธิ์ (ผู้ดูแลระบบ Firebase)
  1. เปิด Firebase Console → Realtime Database → allowed
  2. กด ＋ ที่ allowed → ช่อง Key วาง UID ข้างบน
    ช่อง Value พิมพ์ "admin" (แอดมิน จัดการทะเบียนครุภัณฑ์ได้) หรือ true (เจ้าหน้าที่ทั่วไป บันทึก PM/สอบเทียบ/ซ่อมได้) → Add
  3. กลับมาหน้านี้แล้วกด ลองอีกครั้ง
รหัสครุภัณฑ์ชื่อ / ประเภทผู้รับผิดชอบ PM ครั้งถัดไปสอบเทียบครั้งถัดไปสถานะ

🛠 การบำรุงรักษา (PM)

วันที่ทำรายละเอียดผลตรวจครั้งถัดไปผู้บันทึก

📏 การสอบเทียบ (Calibration)

วันที่สอบเทียบบริษัท/หน่วยงานผลเลขที่ใบรับรองนัดครั้งถัดไปผู้บันทึก

🔧 การซ่อมแซม

วันที่เสียอาการวันที่ซ่อมเสร็จหน่วยงานที่ซ่อมผลผู้บันทึก

🔔 รายการที่ต้องติดตาม

คำนวณจากวันครบกำหนดครั้งถัดไปที่บันทึกไว้ล่าสุดของแต่ละครุภัณฑ์

⚙️ ตั้งค่าการแจ้งเตือน

เฉพาะแอดมินเท่านั้นที่แก้ไขค่าตั้งได้ — บัญชีของท่านดูได้อย่างเดียว

👤 ชื่อของฉัน

ใช้เติมช่อง "ผู้บันทึก" ให้อัตโนมัติในเครื่องนี้

🔑 สิทธิ์การใช้งาน

เพิ่ม/ถอนสิทธิ์เจ้าหน้าที่ทำผ่าน Firebase Console → Realtime Database → allowed โดยตรง (ดูวิธีใน README.md)
admin = จัดการทะเบียนครุภัณฑ์ (เพิ่ม/แก้ไข/นำเข้า/เลิกใช้งาน) + บันทึก PM/สอบเทียบ/ซ่อมได้ทุกอย่าง
true (เจ้าหน้าที่ทั่วไป) = บันทึก PM/สอบเทียบ/ซ่อม และแก้ไข/ยกเลิกเฉพาะรายการที่ตนเองบันทึกได้ ดูทะเบียนครุภัณฑ์ได้แต่แก้ไขไม่ได้

➕ เพิ่มครุภัณฑ์ใหม่

📥 นำเข้าทะเบียนครุภัณฑ์จาก Excel

คัดลอกข้อมูลจาก Excel (เลือกหลายคอลัมน์แล้ว Ctrl+C) แล้ววางในช่องด้านล่าง เรียงคอลัมน์ตามนี้:
รหัสครุภัณฑ์ · ชื่อ · ประเภท(เครื่องมือ/ครุภัณฑ์) · ผู้รับผิดชอบ · หน่วยงาน · สถานที่ตั้ง · ยี่ห้อ · รุ่น · S/N · วันที่จัดซื้อ(YYYY-MM-DD) · ราคา · แหล่งงบประมาณ · รอบPM(วัน) · รอบสอบเทียบ(วัน) · หมายเหตุ · อีเมลผู้รับผิดชอบ
ต้องมีอย่างน้อย รหัส และ ชื่อ ในแต่ละแถว — คอลัมน์ที่เหลือเว้นว่างได้ (คอลัมน์อีเมลผู้รับผิดชอบเป็นคอลัมน์สุดท้าย ไม่บังคับ)
ระบบดูแลครุภัณฑ์และเครื่องมือวิทยาศาสตร์ · ศูนย์บริการสัตว์ทดลอง มหาวิทยาลัยสงขลานครินทร์
